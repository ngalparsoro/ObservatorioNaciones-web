Arduraduna

Webgune honen arduraduna Ion Ansa Mendizabal da. Garapena eta diseinua: Nora Galparsoro. Harremanetarako: kontaktua@nazioenbehatokia.eus.

Nazioen Hautes Behatokia datuen webgune informatiboa da. Ez du publizitaterik, ez du ezer saltzen eta ez du erabiltzaile-konturik.

Datuak eta edukia

Hauteskunde-emaitzak iturri ofizial publikoetatik datoz; jatorria, lizentziak eta deskarga-datak Iturriak atalean daude. Hautagaitzen izenak emaitza ofizialetakoak dira.

Datuak arretaz prozesatu dira, baina akatsak egon daitezke. Emaitza ofizialak iturri ofizialetan kontsultatu behar dira. Akatsen bat ikusiz gero, idatzi helbide honetara: kontaktua@nazioenbehatokia.eus.

Cookierik ez

Webgune honek ez du cookierik erabiltzen eta ez du bisitarien profilik egiten. Zuk aukeratutako hobespen batzuk (hizkuntza edo ezkerreko tresnak ezkutatuta uztea) zure nabigatzailean bakarrik gordetzen dira, eta ez zaizkigu inoiz bidaltzen.

Pribatutasuna

Ez dugu zure daturik biltzen: ez dago formulariorik ez erregistrorik. Hala ere, webgunea ikusteko zure nabigatzaileak zure IP helbidea bidaltzen die zerbitzu hauei, eta haiek tratatzen dute:

  • GitHub (ostatua; GitHub Inc., Ameriketako Estatu Batuak): webgunea zerbitzatzen du, GitHub Pages bidez, eta bisiten erregistro teknikoak gordetzen ditu, zure IP helbidearekin, segurtasunagatik. Datuak Europar Batasunetik kanpo trata ditzake, Europako Batzordeak onartutako bermeekin.
  • Cloudflare (bisita-estatistikak eta webgunearen erreserbako kopia): estatistikak Cloudflare Web Analytics-ekin egiten dira, cookierik gabe eta datu agregatuekin. Cloudflare-k datuak Europar Batasunetik kanpo trata ditzake, Europako Batzordeak onartutako bermeekin.
  • Mapako irudien zerbitzariak: EOX IT Services GmbH (Austria, Sentinel-2 satelitea) eta, mapa hurbiltzean, Instituto Geográfico Nacional (Espainia, PNOA ortoargazkiak). Mapako irudi-zatiak zuzenean haien zerbitzarietatik kargatzen dira.

Oinarri juridikoa interes legitimoa da (DBEO, 6.1.f artikulua): webgunea eskaintzea eta seguru mantentzea.

Mezu elektroniko bat bidaltzen badiguzu, zure helbidea eta mezua erantzuteko bakarrik erabiliko ditugu, eta ez dizkiegu hirugarrenei lagako.

Zure datuak eskuratzeko, zuzentzeko, ezabatzeko edo haien tratamenduaren aurka egiteko, idatzi kontaktua@nazioenbehatokia.eus helbidera. Erreklamazioa ere aurkez dezakezu Datuak Babesteko Espainiako Agentzian (aepd.es).
