Darrera actualització: 13 d'octubre de 2026.

Responsable

El responsable d'aquest web és Ion Ansa Mendizabal. Desenvolupament i disseny: Nora Galparsoro. Contacte: kontaktua@nazioenbehatokia.eus.

L'Observatori Electoral de les Nacions és un web informatiu de dades. No té publicitat, no ven res i no té comptes d'usuari.

Dades i contingut

Els resultats electorals provenen de fonts oficials públiques; l'origen, les llicències i les dates de descàrrega són a la secció Fonts. Els noms de les candidatures són els dels resultats oficials.

Les dades s'han tractat amb cura, però hi pot haver errors. Els resultats oficials s'han de consultar a les fonts oficials. Si hi veus algun error, escriu a: kontaktua@nazioenbehatokia.eus.

Sense galetes

Aquest web no fa servir galetes ni elabora perfils de visitants. Algunes preferències que tries (la llengua o deixar amagades les eines de l'esquerra) es desen només al teu navegador i mai no se'ns envien.

Privacitat

No recollim les teves dades: no hi ha formularis ni registre. Tot i així, per veure el web, el teu navegador envia la teva adreça IP a aquests serveis, que la tracten:

  • GitHub (allotjament; GitHub Inc., Estats Units): serveix el web, a través de GitHub Pages, i desa registres tècnics de les visites, amb la teva adreça IP, per seguretat. Pot tractar dades fora de la Unió Europea, amb les garanties aprovades per la Comissió Europea.
  • Cloudflare (estadístiques de visites i còpia de reserva del web): les estadístiques es fan amb Cloudflare Web Analytics, sense galetes i amb dades agregades. Cloudflare pot tractar dades fora de la Unió Europea, amb les garanties aprovades per la Comissió Europea.
  • Servidors de les imatges del mapa: EOX IT Services GmbH (Àustria, satèl·lit Sentinel-2) i, en apropar el mapa, l'Instituto Geográfico Nacional (Espanya, ortofotos PNOA). Les tessel·les del mapa es carreguen directament des dels seus servidors.

La base jurídica és l'interès legítim (RGPD, article 6.1.f): oferir el web i mantenir-lo segur.

Si ens envies un correu electrònic, farem servir la teva adreça i el teu missatge només per respondre't, i no els cedirem a tercers.

Per accedir a les teves dades, rectificar-les, suprimir-les o oposar-te al tractament, escriu a kontaktua@nazioenbehatokia.eus. També pots presentar una reclamació davant l'Agència Espanyola de Protecció de Dades (aepd.es).
